# Data Contracts

## Purpose

Define, validate, and evolve data contracts between producers and consumers in the SelOps platform.

## Guidelines

- All inter-service data shapes must be described by versioned schemas.
- Breaking changes require a new schema version and a migration plan.
- Contracts are validated at both producer and consumer boundaries.
